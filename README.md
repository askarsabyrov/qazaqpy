# QazaqPy 🇰🇿

**Қазақша Python: Python кодын қазақ тіліндегі кілт сөздермен жазыңыз.**

Небольшая надстройка над Python для обучения программированию на казахском языке.
QazaqPy переводит ключевые слова в Python и выполняет код на CPython. Обычный
Python-синтаксис, отступы и библиотеки сохраняются. Зависимостей во время выполнения нет.

```python
функция қосу(а, б):
    қайтар а + б

аты = "Әлихан"
жазу("Сәлем, " + аты + "!")

үшін сан ішінде аралық(1, 6):
    егер сан % 2 == 0:
        жазу(сан, "— жұп сан")
```

## Установка и запуск

Нужен Python 3.10 или новее. Скачайте репозиторий и откройте его каталог:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
qpy examples/hello.qpy
qazaqpy examples/functions.qpy
qpy examples/guess.qpy
```

В Windows активируйте окружение командой `.venv\Scripts\activate`.
Название `qazaqpy` в pyproject.toml не означает, что пакет опубликован на PyPI.

Запуск из корня проекта без установки:

```bash
python3 -m qazaqpy examples/hello.qpy
```

Аргументы после имени файла передаются программе через `sys.argv`:

```bash
qpy program.qpy first second
```

Посмотреть перевод и сохранить исполняемый Python-файл:

```bash
qpy --transpile examples/functions.qpy > functions.py
python functions.py
```

Переведённый файл использует установленный пакет `qazaqpy` для казахских имён встроенных функций.

## Как работает

Python `tokenize` выделяет токены. QazaqPy заменяет только целые токены `NAME`,
соответствующие словарю ключевых слов. Строки и комментарии сохраняются;
число строк не меняется. Полученный код компилируется и выполняется Python.
Казахские имена встроенных функций добавляются в глобальное пространство программы;
их можно переопределять, как обычные имена. Английские имена тоже работают.

```python
импорт math
жазу(math.sqrt(144))
жазу("егер — бұл сөз жолдың ішінде өзгермейді")
```

## Ограничения версии 0.1

- Казахские ключевые слова зарезервированы: не используйте их как имена переменных или атрибутов.
- F-строки не поддерживаются и отклоняются явно. Используйте `"Сәлем, {}!".format(аты)` или сложение строк.
- Импортируются обычные Python-модули `.py`; автоматический импорт `.qpy` пока не реализован.
- Сообщения Python и traceback остаются на английском. В traceback отображается переведённый код.
- Это учебный препроцессор, а не отдельный интерпретатор или песочница. Запускайте только доверенный код.
- Казахские термины — начальный вариант словаря проекта, открытый для обсуждения.
